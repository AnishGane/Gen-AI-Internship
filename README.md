## Getting Started

This project uses `[uv](https://docs.astral.sh/uv/)` for environment and dependency management.

```bash
git clone https://github.com/AnishGane/Gen-AI-Internship.git
cd <repo-name>
uv sync
```

Run any exercise file with:

```bash
uv run Week1/day1/01_lists.py
```

## Notes
