## Getting Started

This project uses `[uv](https://docs.astral.sh/uv/)` for environment and dependency management.

```bash
git clone https://github.com/AnishGane/Gen-AI-Internship.git
cd <repo-name>
uv sync
```

Run any exercise file with:

```bash
uv run Week1/day1/01_lists.py
```

## Notes

- Each day's folder contains standalone Python files covering that day's learning topics.
- Files are named with a running number prefix (`01_`, `02_`, ...) to keep them in learning order across the whole week.
- Update this README as new weeks/days are added.
